# 模拟盘策略选择与运行说明

## 推荐做法

以 5 分钟均线交叉为入门基线，增加 ATR/价格波动过滤、人工维护的重大事件禁入时段、单品种单方向持仓、单日已实现亏损后停止新开仓。第一版只做历史 CSV 回放，输出模拟交易、每日汇总和 JSON 统计，不连接任何交易账户。

**关于新闻/舆情波动：**没有指标能可靠预知突发新闻、政策变化或跳空。ATR 过滤只会在波动已经升高后减少新开仓；CSV 中的 `event_blackout` 由使用者根据已知事件日历手动标注，不能自动覆盖未知事件。持仓期间仍可能遇到快速反向或跳空，因此这不是“没有大波动”的保证。

## 回放规则

- 只做多：EMA(9) 上穿 EMA(21) 产生入场信号；下穿产生退出信号。可通过命令行调整均线窗口。
- 收盘后生成信号，下一根 5 分钟 bar 开盘价模拟成交，避免在信号 bar 收盘价上假设即时成交。
- 只有 ATR/收盘价低于上限才允许新开仓；默认上限 0.4%。ATR 是风险过滤，不是止损保证。
- 信号 bar 或拟成交 bar 标记了 `event_blackout` 时不新开仓；现有仓位仍按均线信号或样本结束规则退出。
- 手续费、滑点、数量、合约乘数和日亏损阈值均可配置。默认乘数为 1 只是通用演示占位值，务必按所选合约核实，不能把默认结果当成真实期货盈亏。
- 日内亏损限制按已平仓净盈亏判断，只阻止后续开仓，不会保证盘中浮亏不越线。

## CSV 格式

必需列：`timestamp,open,high,low,close,volume`。时间用 ISO 格式，例如 `2025-02-18T09:35:00+08:00`。可选列 `event_blackout` 使用 `true/false` 或 `1/0`。

CSV 应来自有权使用的数据源，时间戳按交易所时区处理，按时间升序且不重复。正式验证还需正确处理夜盘、休市、合约换月、缺失 bar、涨跌停及手续费规则。

## 运行

需要 Python 3.10 或更新版本，无第三方包。Windows PowerShell 示例：

```powershell
python .\paper_replay.py ..\work\sample_5m_synthetic.csv --symbol DEMO --fast 9 --slow 21 --max-atr-pct 0.004 --daily-loss-limit 1000 --multiplier 1 --fee-per-side 2 --tick-size 1 --slippage-ticks 1 --output-dir .\replay_output
```

将输入文件换成你的授权历史 CSV。运行后生成：

- `trades.csv`：逐笔开平仓价、方向、数量、毛/净盈亏、费用、滑点估算及信号原因。
- `daily_diagnostics.csv`：有已平仓交易日期的日汇总。
- `summary.json`：回放参数、样本量、胜率和总净盈亏。

要人工避开已知事件窗口，在对应样本 bar 的 `event_blackout` 列标 `true`。此版本不含智能日历，也不连接实时行情。

## 前端回测页

打开 `http://127.0.0.1:8765`，从侧栏进入“策略回测”。页面内可选择 EMA/SMA、快慢线、ATR 门槛、手续费、固定滑点、乘数、手数、初始权益和时间顺序切分；先导入行情 CSV，并手动填写成本和乘数。CSV 在浏览器选择后会发往本机服务端进行校验、回测并持久化结果。请使用有权使用的数据。

回测结果包括全样本净收益率、逐 bar 权益最大回撤、胜率、盈亏因子、交易数、策略对买入持有基准曲线、训练段/测试段表现和逐笔记录；交易表可导出 CSV。信号只用当前及过去 bar 计算，下一根 bar 开盘成交。切分处会先清仓，再从测试段开始评估，避免一笔交易跨训练/测试段。

训练/测试切分只是基础样本外检查，不等同于完整 walk-forward 验证，也不会自动寻找最优参数。当前前端模型为单品种、只做多、固定数量的简化撮合，不模拟保证金、复合仓位、交易时段、夜盘、换月、涨跌停、盘口冲击、部分成交和真实期货费率。请把输出视为教学结果。

## 策略库与问答

在“我的策略库”页面常态只展示策略摘要和“详细 / 编辑 / 删除”操作。点击详细或编辑、新建时，会打开弹窗再显示参数；删除前会显示“是否确认删除”的确认框。策略库存放于本地 SQLite 服务数据库；服务未启动时操作会报错，不使用浏览器本地存储作为备用。回测页顶部选择已保存策略并载入后运行。

GLM 仅用于“智能问答”页面，不生成策略，不执行模型代码。首次使用在智能问答页配置轮换后的 API Key。Key 只保存在本机服务进程内存，不写入浏览器存储、策略库或源码；关闭服务即清除。也可启动服务前配置 `GLM_API_KEY` 环境变量，模型可用 `GLM_MODEL` 覆盖（默认 `glm-5`）。模型调用会消耗账户额度。此前 Key 曾直接出现在聊天内容中，必须先在 GLM 控制台撤销并轮换，再把新 Key 输入智能问答页。回测实际支持双均线、ATR 和 RSI 超买过滤；MACD/布林带当前仍不参与计算。

## 启动前后端联调

需要 Python 3.10+，不需要安装第三方依赖。PowerShell 在 `outputs` 目录运行：

```powershell
python .\server.py 8765
```

然后浏览器访问 `http://127.0.0.1:8765`。打开页面后，策略创建/修改/删除通过 `/api/strategies` 写入 SQLite；回测页会把所选策略、参数和行情 bar 提交给 `/api/backtests`，服务端计算并保存结果。页面会展示服务连接状态和最近回测记录。服务只绑定 `127.0.0.1`，按 `Ctrl+C` 停止。

新运行数据保存在 `work/runtime/qice.sqlite3`。旧 JSON 文件保留为未导入备份；其回测数据源无法核实。前端所有业务页面需通过本地服务访问，直接双击 HTML 不支持 API 交互。

## 策略交易

从侧栏进入“交易”，导入一份有权使用的历史行情 CSV，选择已保存策略并填写该运行的初始资金、合约乘数、手数、手续费、最小变动价位和滑点。确认合约参数后启动。可继续选择其他策略并分别启动；每条运行拥有独立账户和交易记录，最多同时运行 10 条。

运行页会逐 bar 自动推进历史行情。取消某条策略只停止该策略；如有持仓，系统会按最后处理 bar 的收盘价模拟平仓并记入费用。完成和取消的运行记录会继续保留。浏览器关闭期间不推进；重新打开页面后，仍标记运行中的策略会继续推进。

该功能只做历史行情驱动的 paper trading，不是实时行情或实盘交易。真实撮合、交易时段、夜盘、换月、保证金、涨跌停、盘口冲击、部分成交和真实期货费率仍未覆盖。
